# Brand Decisions — Narrow Center / Living Edge

## Positioning
A chaordic governance field guide for AI agent fleets.

## Core line
Govern fewer things absolutely. Observe many things continuously.

## Visual system
- **Mark:** nested bracket/seal: hard center, porous edge.
- **Palette:** warm ledger paper, ink, iron, oxidized copper, muted Visa-blue inference line.
- **Typography:** editorial serif for doctrine; geometric sans for operating labels; tabular numerals for governance telemetry.
- **Texture:** ledger lines, audit ticks, authorization stamps, orbital agent traces.
- **Motion:** slow institutional drift, not spectacle. Motion expresses aliveness at the edge and invariance at the center.

## UI motifs
1. Constitutional clauses as ledger entries.
2. Center/edge rails as a persistent vertical divide.
3. Agents as accountable nodes orbiting a revocation core.
4. Policy language generated as field-manual fragments.
5. Diagnostics that ask: centralize, delegate, observe, or forbid?
