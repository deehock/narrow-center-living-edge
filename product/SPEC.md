# Product Spec — Narrow Center / Living Edge

## Premise
An AI agent fleet should not be governed like a software stack. It should be governed like a network association: narrow invariant rails at the center, wide experimentation at the edge.

## Artifact
A production-quality single-page web app that teaches the frame through interaction.

## Required sections
1. Hero doctrine + animated typographic network.
2. Center/Edge diagnostic showing what belongs where.
3. Six common rails: identity, authority, budget, memory, audit, revocation.
4. Charter builder that generates a compact operating charter for an agent.
5. Anti-patterns: god-agent bureaucracy and credentialed chaos.
6. Operating cadence: observe, intervene, prune, renew.

## Acceptance criteria
- App builds with TypeScript.
- Works without backend.
- Responsive from mobile to desktop.
- Accessible labels and reduced-motion support.
- Distinct brand system in code.
- At least one meaningful interactive tool.
- Test coverage for governance classification and charter generation.
